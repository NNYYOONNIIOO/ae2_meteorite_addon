# AE2 Meteorite Addon

**AE2 Meteorite Addon** is a mod that enhances the meteorite mechanics in AE2.

## Overview

- **Annihilation Plane Addon:** When placed at Y=254 or Y=255, the Annihilation Plane will generate meteorite dust and store it directly into the network.
- **Meteorite Addon:** Generates 9 Certus Quartz Motherstones within a 9×9 area centered on the meteorite (offset by -1), similar to the modern version of meteorites.

Textures courtesy of the AE2 team.
